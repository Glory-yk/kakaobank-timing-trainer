# Timing Workspace

카카오뱅크 오픈런을 준비하며 만든 서버시간 타이머를, 공개 웹사이트에 사용할 수 있도록 확장한 개인용 오픈소스 도구입니다.

> URL을 입력하면 해당 사이트의 HTTP `Date` 헤더를 기준으로 서버 시각을 추정하고, 목표 시각에 맞춰 터치 연습을 할 수 있습니다.

## 왜 만들었나

카카오뱅크 주택담보대출 오픈런을 여러 번 시도하면서, 단순히 현재 시간을 보여주는 것만으로는 부족하다는 걸 경험했습니다. 목표 시각을 정하고, 신호등과 소리로 리듬을 익히고, 실제로 눌렀을 때 얼마나 빨랐는지 기록하는 도구가 필요했습니다.

처음에는 카카오뱅크 전용으로 만들었지만, 수강신청·티켓팅·선착순 이벤트처럼 특정 시각이 중요한 다른 상황에도 쓸 수 있도록 URL 입력 방식으로 바꿨습니다.

## 기능

- 공개 URL의 서버시간 동기화
- HTTP `Date` 헤더 기반의 시각 추정 및 왕복시간(RTT) 표시
- 5초·10초 훈련과 60초 정각 실전 모드
- 3-2-1 시각 신호등, 비프음, 진자 애니메이션
- 터치 결과의 `PERFECT`·`SAFE`·`DANGER`·`EARLY`·`LATE` 판정
- 시도 횟수·골든존 적중률·통과율·평균 터치 시각 기록
- 로컬 실행으로 PC 화면과 모바일 기기에서 함께 사용

## 실행

### Mac / Linux

```bash
chmod +x start.sh
./start.sh
```

### Windows

`start.bat`을 더블클릭하거나 명령 프롬프트에서 실행합니다.

브라우저에서 `http://localhost:8080`을 열고, 상단 URL 입력창에 서버시간을 확인할 공개 사이트를 입력합니다. 같은 Wi-Fi의 휴대폰에서는 실행 시 터미널에 표시되는 로컬 IP 주소로 접속할 수 있습니다.

## 동작 원리와 한계

1. 서버에 여러 차례 요청을 보냅니다.
2. 응답의 HTTP `Date` 헤더와 요청 왕복시간을 이용해 서버 시각과 로컬 시각의 오프셋을 추정합니다.
3. 응답의 초 경계가 바뀌는 순간을 감지해 밀리초 단위 표시를 보정합니다.

HTTP `Date` 헤더는 원본 애플리케이션 서버가 아니라 CDN·프록시의 시각일 수 있습니다. 또한 브라우저·네트워크·휴대폰의 지연은 별도로 발생합니다. 따라서 이 도구는 성공을 보장하는 자동 신청기가 아니라, 중요한 순간의 준비와 타이밍 연습을 돕는 도구입니다.

서버는 공개 HTTP(S) 주소만 허용하고, 로컬·사설 네트워크 주소와 자동 리디렉션은 차단합니다. 로그인·결제·신청 요청을 대신 보내지 않습니다.

## 주의

- 서비스가 `Date` 헤더를 제공하지 않으면 서버시간을 표시할 수 없습니다.
- 서버시간과 실제 신청 시스템의 판정 시각이 다를 수 있습니다.
- 이 도구를 사용하더라도 최종 신청·결제·제출은 사용자가 직접 확인해야 합니다.
