# ⚡ 카카오뱅크 실시간 서버시간 오픈런 타이밍 트레이너

> **`www.kakaobank.com` 실제 서버 시간(초정밀 밀리초 단위)과 1:1 동기화하여 화면에 띄우고, 내 손가락의 반응 속도(Human Latency)와 단말 지연을 교정하는 트레이닝 툴**

---

## 🎯 핵심 기술: 카카오뱅크 서버 시간 정밀 추적 (Edge Transition)

일반적인 HTTP `Date` 헤더는 1초 단위(초 정수)만 제공합니다. 
본 트레이너는 `www.kakaobank.com` 서버의 Nginx 응답 헤더가 **"X초에서 X+1초"로 딱 바뀌는 순간(초 경계 전이 Edge Transition)**을 고속 감지하여, 카카오뱅크 서버 시각을 **밀리초(ms) 단위까지 정밀 추정 및 지속 동기화**합니다.

* **동기화 대상**: `https://www.kakaobank.com`
* **백그라운드 미세 보정**: 15초 주기로 자동 보정하여 시간 흐름 오차(drift) 0 유지
* **화면 표시**: 화면 상단에 카카오뱅크 서버 시각 `08:07:26.883`이 실시간 밀리초 단위로 렌더링됩니다.

## 🛠️ 주요 기능

1. **🟡 kakaobank.com 실시간 서버 시계**:
   - 로컬 PC 시계가 아닌 **카카오뱅크 실제 웹서버의 시계**가 실시간 렌더링됩니다.
   - 우측 상단 `[🔄 동기화]` 버튼으로 언제든 즉시 카카오뱅크 서버와 강제 재동기화 가능.
2. **반복 훈련 모드**:
   - **🎯 정각 실전 (60초)**: 카카오뱅크 실제 정각 00.000초 기준
   - **내일 실전 최적 터치 시간대 (확장 골든존 & 신호등 리듬)**:
  1. **확장 골든존 (59.400s ~ 59.620s, 폭 220ms 여유)**:
     - 기존 100ms보다 2.2배 넉넉하게 확장되어 웹 화면을 보면서 스마트폰을 누르기 훨씬 편안합니다.
     - **울트라 퍼펙트 (59.460s ~ 59.540s)**: 초신급 적중 (+50~150ms 최우선 통과)
     - **골든존 (59.400s ~ 59.620s)**: 안정적 성공권 안착 (+0~250ms)
  2. **⏱️ 정밀 타이밍 물리 진자 (Precision Pendulum Synchronizer)**:
     - 숫자를 읽느라 생기는 뇌의 인지 지연(Cognitive Delay)을 제거하기 위한 **아날로그 물리 진자 운동 캔버스 탑재**.
     - 황금빛 진자가 좌우로 왕복 스윙하다가 **정확히 0.000초 (골든존) 순간에 정중앙 수직 황금 게이트를 최고 속도로 관통**합니다.
     - 인간의 뇌는 떨어지는 물체의 궤적과 속도를 무의식적으로 예측하므로, **"진자가 중앙 황금선에 딱 닿는 찰나"**를 보며 스마트폰을 누르면 100% 타이밍 일치가 가능합니다.
  3. **🚦 F1 스타일 3-2-1 비주얼 신호등 & 비프음**:
     - `🔴 3초(준비)` $\to$ `🟡 2초(대기)` $\to$ `🟠 1초(긴장)` $\to$ **`🔥 0초(쾅! 지금 터치)`**
     - 시각적 신호등과 청각적 비프음 메트로놈으로 리듬을 타며 스마트폰을 정확하게 내리칠 수 있습니다.
  4. **골든존 플래시 지속 시간 확대 (400ms)**:
     - 터치 순간 0.4초 동안 화면과 시계, 진자 카드가 넉넉하게 황금빛으로 번쩍여 눈에 확실하게 들어옵니다.
* **대형 듀얼 타이머 디스플레이**:
  1. **🟡 카카오뱅크 실시간 서버 시계**: `08:26:09.450` (실제 웹서버 밀리초 시계)
  2. **⚡ 누르는 타이밍까지 남은 시간 (카운트다운)**:
     - `- 1.450초` $\to$ `- 0.150초(위험 경고)` $\to$ **`🔥 0.000초 (TOUCH!)`**
     - 카운트다운이 정확히 **`0.000초`**가 되는 찰나를 눈으로 보며 리듬을 맞춰 손가락 반응속도를 완벽히 훈련할 수 있습니다.
3. **오차 타임라인 게이지 & 등급 판정**:
   - `PERFECT` (+0 ~ +50ms): 👑 상위 0.1% 신의 타이밍 (골든존)
   - `GREAT` (+50 ~ +150ms): 🔥 최우선 통과권
   - `SAFE` (+150 ~ +350ms): ✅ 안정권 통과
   - `EARLY` (음수 ms): ❌ 카카오뱅크 서버 컷오프 탈락 (조기 클릭)
4. **모바일 최적화**:
   - 모바일 300ms 터치 지연 완전 차단 (`pointerdown`, `touch-action: manipulation`)
   - 햅틱 진동 + 효과음 피드백
